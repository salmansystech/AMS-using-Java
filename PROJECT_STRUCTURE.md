# Attendance Management System (AMS) - Java

A desktop application for managing student attendance in educational institutions.

## Features

- Role-based access (Admin, Teacher, Student)
- Student management (add, view, delete)
- Subject management
- Teacher management
- Attendance tracking
- Record viewing

## Architecture

- JFrame-based GUI
- File-based data persistence
- Role-based authentication

## Core Components

- AddStudent, AddTeacher, AddSubject: Data entry modules
- Login system with role-based access
- Attendance management interface
